# Person 3: secondary Stage >=2 handoff

COMP90089 Group 7 · 20 October 2026 · v1

This is an **additional** package. Retain the original Person 3 primary handoff and Person 5's completed primary evaluation.

The target is `aki_stage2_label`: observed Stage 2 or 3 AKI in the same ascertainment window and population used by the primary analysis. Stage 1 and operational negatives remain in the cohort with label 0. Models have been newly fitted to this target; primary model probabilities have not been relabelled.

The frozen Person 2 split, permitted predictors, fitted preprocessing and text vocabulary/IDF are unchanged. The XGBoost sparse-zero correction is not needed for LR.

## Contents

- `P3_stage2_baselines.ipynb`: executed notebook containing the complete baseline workflow.
- `stage2_baselines.py`: equivalent executable source.
- `aki_preprocessing.py`: byte-identical copy of Person 2's module, required for loading pipelines.
- `outputs/models/*.joblib`: four training-fitted raw-input pipelines.
- `outputs/validation_predictions.csv`: one row per validation encounter, model and target.
- `outputs/validation_metrics.csv`, `tuning_record.csv`, `development_cohort_counts.csv`: development results and full fixed-grid search.
- `outputs/analysis_plan.json`, `model_metadata.json`, `handoff_checks.csv`, `independent_validation_checks.json`: protocol, provenance and verification.
- `P3_stage2_report_contribution.md`: detailed secondary methods and validation results.
- `P3_report_ready_text.md`: concise English baseline contribution using Person 5's primary test results; secondary validation is explicitly separate.
- `P5_stage2_integration.md`: integration contract and remaining evaluation work.
- `DECISIONS_STAGE2.md`: scope and chronology.

## Reproduce

Use Python 3.12 and install `requirements.txt`. Keep these directories beside one another:

```text
Group Project/
  aki_handoff/predictor_columns.csv
  person2_handoff/person2_split_preprocessing/
    aki_preprocessing.py
    outputs/...
  person3_stage2_handoff/
    aki_preprocessing.py
    P3_stage2_baselines.ipynb
    ...
```

Run all notebook cells, or from `Group Project`:

```sh
python person3_stage2_handoff/stage2_baselines.py --project-dir .
python person3_stage2_handoff/verify_handoff.py --project-dir .
```

To rebuild and execute the notebook from source:

```sh
python person3_stage2_handoff/build_notebook.py --execute
```

Rerunning writes only this secondary package's development outputs. No test predictors, outcomes, matrices or predictions are loaded/generated by this workflow. The split manifest is read to verify patient separation across all partitions.

```python
from pathlib import Path
import joblib

bundle = Path("person3_stage2_handoff")
sys.path.insert(0, str(bundle.resolve()))
pipeline = joblib.load(bundle / "outputs/models/structured_text_lr.joblib")
assert pipeline.target_name_ == "aki_stage2_label"
# X contains exactly the 13 cleaned predictors, without stay_id or labels.
probability = pipeline.predict_proba(X)[:, 1]
```

Model names match the primary handoff, so use **(target, model_name)** as the integration key. These models accept Person 2's cleaned raw inputs, not the XGBoost matrices. Read the integration note before final evaluation.

The notebook displays aggregate results only. Row-level predictions and fitted models belong in the team's approved private storage.
